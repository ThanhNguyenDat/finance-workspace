# Tài liệu lưu trữ

Thư mục này giữ các note, plan và spec lịch sử đã hoàn thành hoặc bị thay thế.
Không dùng chúng để mô tả hành vi production hiện tại và không mở task mới từ
đây nếu chưa chuyển nội dung cần thiết sang `docs/specs/` hoặc `docs/runbooks/`.

- `notes/`: kết quả điều tra/thiết kế theo từng đợt.
- `superpowers/plans/`: kế hoạch triển khai dashboard cũ.
- `superpowers/specs/`: spec cũ; decision pipeline hiện hành đã được đưa lên
  [`docs/specs/trading-decision-pipeline.md`](../specs/trading-decision-pipeline.md).

Nội dung dưới `legacy-raw/` và `legacy-handoff-agent.md` chỉ là lịch sử
non-authoritative từ namespace đã retire; archive này không phải task queue
hay nơi tạo artifact mới.
